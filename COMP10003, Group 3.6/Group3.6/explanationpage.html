Explanation

Noah Irwin

I decided to create separate pages for each of my assigned microwaves, making accessibility more defined for ease of access. Additionally, I made the pages match the cohesive aesthetic colouring of unimelb.edu.au, further enhancing user accessibility. I also wanted each page to be interacted with, so the use of hyperlinks, smooth animations, and image carousels (requiring some JS, with help from W3Schools) are prevalent throughout.

Quinn McShane

Gemini said I focused on making my microwave pages easy to use by organizing the info into cards so it's not just a wall of text. I used the official UniMelb dark blue color for the top and bottom bars to make it look professional and match the rest of the group's work. I also added a comment box at the bottom using a textarea so people can leave their own reviews. Right now, the textarea doesn't actually save anything yet, but I'm going to fix that and make it work for part 2. For the layout, I used flexbox to keep the pictures and the directions side-by-side so the page stays clean. Finally, I made sure the fonts stayed the same across my pages by importing Fraunces and Source Sans 3 so everything looks cohesive.

Max Finch

I have used a hyperlink at the bottom of the page, which returns the user to the home page. I have also used a table to display the ratings for each category the microwave has achieved. The styling on my page is very simple, using only one font at varying sizes. The colours used are all cohesive, one being a dark blue for the heading and the footer, similar to the colour used on Unimelb pages, as well as a light blue, which is used to separate each section.

Seng Kuan Chan

- Implement tag with a href = “” to direct my page to direct the user into the home page and individual microwave page. Target = “_blank” is also used to always open a new tab - Implement @keyframes animation tag in css to create slide up animation when page loads - Used the same header and footer to keep the styling consistent

Mahmudul Hasan Rafi

I have put my CSS and JS within my HTML file so that it is easy for me to navigate my work. Moreover, I put in a system where viewers can rate the ovens and sum the total rating so they can compare each oven with numbers. I have also put a 'Go up' button in the right corner to make it easy for viewers, and I have also added a hover effect to make the images appear bigger when someone interacts with them.
